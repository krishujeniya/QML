Quantum computing for machine learning

Build from state vectors to variational models. Each lesson states the math and the assumptions; the labs run locally in your browser and use small, exact simulations.

What this is: an educational state-vector simulator for one qubit. It is not quantum hardware and does not demonstrate computational advantage.

1. States, amplitudes, and measurement

A pure state of one qubit is a normalized vector in a two-dimensional complex space. In the computational basis, write it as |ψ⟩ = α|0⟩ + β|1⟩, where |α|² + |β|² = 1. Measuring in that basis returns 0 with probability |α|² and 1 with probability |β|². A single measurement is one sample; repeated shots estimate the probabilities.

Global phase does not change measurement statistics. Relative phase can matter when later gates interfere amplitudes. The Bloch sphere depicts pure single-qubit states, with antipodal points representing orthogonal states.

2. Gates are unitary transformations

A gate maps the state vector through a unitary matrix. For example, the Hadamard gate maps |0⟩ → (|0⟩ + |1⟩)/√2. Measuring immediately then gives either result with equal probability. Applying H again returns |0⟩: amplitudes interfere, so probabilities are not classical uncertainty over hidden bit values.

4. Entanglement and correlated outcomes

Two qubits have a four-dimensional state space. The Bell state (|00⟩ + |11⟩)/√2 cannot be written as a product of two single-qubit states. Measuring both qubits in the computational basis gives perfectly correlated outcomes: 00 or 11, each with probability one half. The individual outcomes are random; correlation does not let either party choose or signal the result.

5. From circuits to a learning model

A common QML pattern encodes input data into a parameterized circuit, measures an observable, then uses a classical optimizer to update parameters. A typical binary classifier maps an expectation value to a score and compares that score with labels. The circuit is only one component: data representation, measurement cost, optimizer behavior, and the chosen classical baseline all matter.

Mini-lab · parameterized one-qubit classifier sketch

For a single input x and trainable angle w, prepare RY(x) RY(w)|0⟩ and measure Z. The exact expectation is cos(x + w). Adjust the angles and see how the score changes. This is a circuit calculation, not a trained benchmark.

For practical study, implement a small classifier in a simulator and report the dataset, split, encoding, circuit depth, shots, optimizer, and a tuned classical baseline. Keep train and test data separate.

Mini-lab · train the circuit

The four fixed examples use x = −1.5, −1, 1, 1.5 radians, with labels +1, +1, −1, −1. The model predicts ⟨Z⟩ = cos(x + w). Train w by minimizing mean squared error. Its gradient is computed with the two-shift rule for this single Pauli rotation: f′(w) = [f(w + π/2) − f(w − π/2)]/2. This tiny, noiseless training demo is only for learning the mechanics.

6. Read QML claims carefully

A quantum circuit formulation or a successful toy simulation does not establish useful quantum advantage. Results depend on a precise task and cost model, how inputs reach the device, measurement/sample complexity, noise, and the strength of classical alternatives. Variational circuits can also encounter training difficulties such as barren plateaus under particular assumptions; this is an active research topic, not a universal behavior of every circuit.
